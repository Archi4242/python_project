# python_project
Python project on Apollo Hospitals - Appointment No-Show and Patient Engagement Analysis 

Overview
Apollo Hospitals operates across 15 Indian cities through in-clinic, video-consult, and home-visit appointments booked via five channels (App, Website, Call Centre, Walk-In, Partner App). A meaningful share of booked appointments never happen — hurting doctor utilisation, revenue, and patient outcomes.
This project performs a full exploratory data analysis on 75,000 appointment records (2022–2024) and a 320-doctor dimension table to answer 21 business questions across five areas:
Business overview — volume trend, outcome mix, booking-channel split
No-show drivers — specialty, city, lead time, time slot, appointment type, channel
Reminders & engagement — reminder effectiveness, prior no-show history, membership
Patient segmentation — age, gender, chronic condition, visit reason
Financial performance & doctor utilisation — revenue lost, revenue mix, wait time, satisfaction

Tools & Libraries used:
Python 3.10 — pandas, numpy
Visualization — matplotlib, seaborn
Statistics — scipy.stats (chi-square, Cramér's V, Pearson/point-biserial correlation)
Environment — Jupyter Notebook
